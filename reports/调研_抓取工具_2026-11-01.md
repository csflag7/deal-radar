# 调研 · GitHub 抓取 / 正文提取 / 网页监控工具（2026-11-01）

来源：researcher（haiku）。star 数、最后一次 push、许可证取自 GitHub API，核实于 2026-11-01 至 11-02。原则：不采用规避网站防护的工具。

## 结论（推荐接入）
| 用途 | 推荐 | 理由 |
|---|---|---|
| 新闻正文抽取（替换自写的 HTMLParser） | **trafilatura**（Apache-2.0，7.1k）；失败时退到 readability-lxml | 去掉模板和侧栏，能直接输出 markdown 给 LLM，只加一个依赖 |
| 发布日期 | htmldate（Apache-2.0） | 补上缺失的发布日期，旧闻过滤更准 |
| JS 渲染的页面 | playwright-python（只用于白名单站点） | 标准方案，Actions 上能装 |
| 网页变化监控 | 不加依赖：httpx + trafilatura 文本做 sha256 比对；要现成工具就用 urlwatch | 只有内容变了才交给 LLM，省钱 |
| PDF 促销条款 | markitdown（MIT） | 本地运行 |

## 不采用
- firecrawl（付费 / 自托管太重）、scrapy / crawlee（对固定 URL 清单太重）、scrapegraph-ai、browser-use（不确定性大、成本高）、news-please（已归档）
- crawl4ai：只部分适合（依赖里有反检测库）
- undetected-chromedriver、FlareSolverr：规避网站防护，不采用

## 可借鉴的开源项目
- gitAbid/deal-radar（TS，无许可证，只借鉴思路）：约 100 个商家的促销页 watchlist + 社区源，LLM 抽取，带置信度下限，Actions 定时，排除禁止采集的商家
- appstore-discounts：优先用官方 API，按地区输出 RSS
- 黑五 / 网一的日期可以直接用代码算（感恩节后的周五和下周一）

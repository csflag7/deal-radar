# 调研 · 购物车比价的价格数据来源（2026-11-01）

来源：researcher（sonnet）。原则：只用合法、条款允许的方式。

## 能合规拿到的只有三条线
| 来源 | 覆盖 | 价格 | 费用 | 门槛 / 条款 |
|---|---|---|---|---|
| Best Buy 美国官方 API | 美 | 当前价（含促销价），没有历史价 | 免费，5 万次/天 | 填注册表；许可写的是“面向客户的应用”，个人自用算灰区 |
| SerpApi（Google Shopping） | 美 + 加（gl 参数） | 当前价，带零售商名 | 免费 250 次/月；$25/月 1000 次 | 注册；Google 起诉 SerpApi 的部分诉讼已被驳回，仍属灰区（风险在厂商一侧） |
| Keepa API | Amazon 美 + 加 | 当前价 + 历史价 | 约 €49/月起（第三方数字，官方页没抓到） | 信用卡，月付，可随时取消 |

## 走不通
- Amazon PA-API / Creators API：要有联盟销售记录（PA-API 已停用）
- Walmart 联盟 / Open API：条款禁止价格追踪和提醒功能
- bestbuy.ca：没有公开 API
- Google Content API：已经日落
- PriceCanada：停放域名；pricehistory.ca：打不开
- CamelCamelCamel：没有 API，只能人工设提醒
- 联盟平台的商品 feed（Impact/CJ/Awin/Rakuten）：要有推广站点并通过审核，不适合个人

## 费用估算
- 30 件商品、每天查一次：SerpApi $25 + Keepa ~$55 ≈ **$80/月**；美加分开查约 $130/月
- 省钱方案：商品少于 8 件或隔天查一次 → SerpApi 免费额度够用，只付 Keepa；或者先只用免费的 Best Buy API + SerpApi 免费额度

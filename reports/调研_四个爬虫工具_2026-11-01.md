# 调研 · 用户点名的 4 个爬虫工具（2026-11-01）

来源：researcher（sonnet），核对了 GitHub README、官方文档和 GitHub API。原则：不使用任何规避或反检测功能。

| 项目 | 关掉规避功能后还剩什么价值 | 规避功能（全部不用） | 重量 / 要求 | 结论 |
|---|---|---|---|---|
| **Crawl4AI**（Apache-2.0，8.67 万 star） | JS 渲染；Fit Markdown；AsyncUrlSeeder 读 sitemap，按关键词给 URL 打分；block 检测（只报告，不绕过） | enable_stealth、UndetectedAdapter、simulate_user、override_navigator、随机 UA、代理轮换（全部默认关） | pip + crawl4ai-setup 装 Chromium；不需要 key 或 Docker；**Python≥3.10** | **主力** |
| Scrapling（BSD-3，9.18 万） | 解析器 + 自适应选择器（网站改版后还能重新定位） | Fetcher 默认模拟 Chrome 的 TLS 和请求头；StealthyFetcher 自动打反检测补丁；solve_cloudflare | 只装解析器很轻；Python≥3.10 | 只用解析器 |
| crawlee-python（Apache-2.0） | 队列和重试 | 浏览器指纹默认开（可关）、会话池、retry_on_blocked | Python≥3.10 | 暂时不用 |
| Crawlee（JS） | — | 指纹、TLS 模拟 | Node | 语言不对 |
| Firecrawl（AGPL-3.0） | 自托管只剩 Playwright + Markdown | 托管版自动升级代理 | 自托管要起 5 个服务 / 云端要 key | 太重，不用 |

## 使用约定（Crawl4AI）
user_agent="DealRadar/0.1 (personal deal calendar)"、check_robots_txt=True、max_retries=0；stealth、undetected、magic、代理一律不开；被拒（403 / Access Denied）的网站记下来，转人工 Chrome 扫描。
结论：在不规避的前提下，这 4 个工具都帮不上已经拦截程序的网站（Canadian Tire、Walmart.ca、Sephora 等）。
